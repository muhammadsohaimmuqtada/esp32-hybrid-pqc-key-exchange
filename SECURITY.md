# Security policy

This project is intended for authorized security testing, research, and educational use only. It must only be directed at systems and identities you are explicitly authorized to test, or at researcher-controlled lab environments.

## Operating boundary

- Limit active testing to targets you own or have written authorization to assess.
- Do not use this tool in a manner that violates applicable law or any system's terms of service.
- Use researcher-controlled objects, identities, and data when evaluating behavior.

## Reporting vulnerabilities in this project

Please avoid publishing an unpatched vulnerability before maintainers have had a reasonable opportunity to reproduce and address it. Open a private security advisory when available, or contact the repository owner directly through GitHub.
